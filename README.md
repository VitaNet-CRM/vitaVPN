# VitaNet / vitaVPN

[صفحهٔ دانلود مشترک اندروید و ویندوز](https://github.com/VitaNet-CRM/vitaVPN/releases/tag/v1.0.18)

## Android 1.0.16 / Windows 1.0.15

دانلود اندروید و ویندوز در همین صفحه است. برای بیشتر گوشی‌های جدید فایل arm64-v8a مناسب است. در ویندوز فایل Setup معماری مناسب را انتخاب می‌کند؛ نصب‌کننده‌های آفلاین x64 و x86 هم موجودند.

- نمایش تمدید بعدی با نام واقعی محصول، به رنگ سبز؛ با پایان اشتراک فعلی، دورهٔ بعدی طبق تنظیمات سرور خودکار فعال می‌شود.
- نمایش همزمان هشدار اشتراک و پیام تمدید در جای تصویر پایین، با متن‌های وسط‌چین و بدون بزرگ‌شدن یا پرش صفحه.
- پیام‌های کوتاه پس از سه ثانیه به‌آرامی محو می‌شوند؛ پیام‌های بیشتر در همان فضای ثابت نوبتی نمایش داده می‌شوند.
- نمایش جداگانهٔ مدت کامل اشتراک و روزهای باقی‌مانده؛ حفظ طراحی بخش مصرف.

فایل جدید را روی نسخهٔ قبلی نصب کنید؛ برنامه را حذف نکنید تا فعال‌سازی و تنظیمات حفظ شوند. اتصال همان دستگاه ممکن است هنگام نصب کوتاه قطع شود. انتشار فایل‌ها نیاز به توقف سایت یا VPN سرورها ندارد.

اصلاحات قبلی اتصال، خروج امن، کپی کد اصلی و دریافت کد از تصویر QR حفظ شده‌اند. امضای اندروید و اعتبارسنجی امضا و هش به‌روزرسانی ویندوز حفظ شده است. نصب‌کنندهٔ ویندوز هنوز امضای Authenticode ندارد.

حداقل Android 7.0؛ Windows 10/11 x64 و Windows 10 x86. نسخهٔ ARM64 ویندوز ارائه نمی‌شود. تست چیدمان و پیام‌ها روی ویندوز و شبیه‌ساز Pixel انجام شده؛ گوشی فیزیکی، سخت‌افزار Windows x86 و گذار طبیعی یک تمدید مالی به دورهٔ فعال آزمون نشده‌اند. استثنای DNS تلگرام در حالت تونل روی شبکهٔ محلی مالک، جزو اصلاحات این انتشار نیست.

نسخه‌های سالم قبلی محفوظ‌اند. هش فایل‌ها در SHA256SUMS.txt است. سورس اپ‌ها خصوصی است؛ آرشیو خودکار گیت‌هاب متعلق به مخزن دانلود است.
