# VitaNet / vitaVPN

[دانلود Android و Windows نسخهٔ 1.0.19](https://github.com/VitaNet-CRM/vitaVPN/releases/tag/v1.0.19-final-20261027)

## Android 1.0.19 / Windows 1.0.19

نسخه‌های Main، Emad و Mehrdad جدا هستند. برای نسخهٔ اختصاصی، فایل همان نام را دریافت کنید؛ برند، قابلیت تلگرام و کانال به‌روزرسانی هر نسخه حفظ شده است.

برای بیشتر گوشی‌ها arm64-v8a مناسب است. اندروید چهار معماری دارد؛ Windows فایل‌های MSI با معماری x64 و x86 و نصب‌کنندهٔ Setup برای نسخهٔ اصلی دارد.

- کاهش کار تکراری پس‌زمینه و سنجش متعادل کیفیت اینترنت؛ میزان صرفه‌جویی شبانهٔ باتری هنوز اندازه‌گیری نشده است.
- هشدار خاموش‌کردن فیلترشکن‌های دیگر پیش از فعال‌سازی؛ حفظ کد واردشده.
- یک کارت خوانا برای کیفیت ضعیف اینترنت و اصلاح اعلان‌های آن.
- اصلاح نصب به‌روزرسانی ویندوز، جهت نوار پیشرفت فارسی و نمایش دکمه.

هشدار Google Play Protect در بعضی نصب‌های اندروید همچنان گزارش شده و رفع‌شدن آن تأیید نشده است. حفاظت دستگاه را خاموش یا دور نزنید.

روی نسخهٔ قبلی نصب کنید تا فعال‌سازی حفظ شود. نصب می‌تواند اتصال همان دستگاه را موقتاً قطع کند؛ انتشار فایل‌ها نیازی به توقف سایت یا VPN سرورها نداشت.

۳۷۷۴ تست JVM اندروید موفق‌اند. نصب همهٔ نسخه‌های اختصاصی روی گوشی واقعی و سیستم‌عامل ویندوز ۳۲بیتی آزموده نشده است. امضای APK و اعتبارسنجی امضا/هش آپدیت ویندوز حفظ شده؛ نصب‌کنندهٔ ویندوز Authenticode ندارد.

هش تمام فایل‌ها در SHA256SUMS.txt است. نسخهٔ قبلی برای بازگشت عرضه محفوظ است؛ اپ نصب‌شده خودکار به نسخهٔ قبلی برنمی‌گردد. سورس‌ها در مخزن‌های خصوصی جداگانه نگه‌داری می‌شوند.
