# VitaNet / vitaVPN

[دانلود Android اصلی 1.0.20، ساخت 90](https://github.com/VitaNet-CRM/vitaVPN/releases/tag/android-v1.0.20-90)

لمس اعلان نسخهٔ جدید مستقیماً صفحهٔ آپدیت را باز می‌کند؛ APK تأییدشده مستقیم به نصاب سیستمی اندروید تحویل می‌شود. مجوز درخواست نصب با تأیید مالک برگشته است؛ نصب نهایی همچنان به تأیید کاربر و اجازهٔ منبع در اندروید نیاز دارد. کنترل هش/امضا و اصلاح تداخل VPN حفظ شده‌اند. چهار معماری ارائه شده‌اند.

۱۲۶۶ تست واحد و ۱۴ آزمون رابط و نصاب در محیط جدا موفق بودند. نصب و اسکن نهایی این ساخت روی گوشی هنوز مستقل تأیید نشده‌اند. رفتار آپدیتر ۱.۰.۱۹ قبل از ارتقا همان مسیر قبلی است؛ تغییرات پس از نصب ساخت۹۰ فعال می‌شوند. حدود آزمون در release-info.json آمده است.

هش فایل‌های همین انتشار در SHA256SUMS.txt است. روی نصب قبلی ارتقا دهید تا فعال‌سازی حفظ شود. نصب می‌تواند اتصال همان دستگاه را موقتاً قطع کند.

## Windows 1.0.19

[دانلود نصب‌کننده‌های Windows](https://github.com/VitaNet-CRM/vitaVPN/releases/tag/v1.0.19-final-20261027)

فایل‌های MSI با معماری x64 و x86 و نصب‌کنندهٔ Setup نسخهٔ اصلی موجودند. اصلاح نصب به‌روزرسانی ویندوز، جهت نوار پیشرفت فارسی و نمایش دکمه در همان انتشار عرضه شده‌اند. امضا و هش بستهٔ به‌روزرسانی کنترل می‌شود؛ نصب‌کنندهٔ ویندوز Authenticode ندارد. ویندوز ۳۲بیتی روی سیستم واقعی آزموده نشده است.

انتشار فایل‌ها نیازی به توقف سایت، دیتابیس یا VPN سرورها نداشت. نسخه‌های قبلی برای بازگشت عرضه حفظ شده‌اند؛ اپ نصب‌شده خودکار به نسخهٔ قبلی برنمی‌گردد. سورس اصلی در مخزن خصوصی نگه‌داری می‌شود.
