# vitaVPN

دانلود رسمی vitaVPN برای **ویندوز و اندروید**؛ رابط فارسی و انگلیسی و مدیریت اتصال و اشتراک از یک حساب.

## ویندوز — نسخهٔ ۱٫۰٫۰

برای **Windows 10/11، پردازندهٔ ۶۴ بیتی x64**:

- [دانلود نصب‌کننده EXE](https://github.com/VitaNet-CRM/vitaVPN/releases/download/windows-v1.0.0/vitaVPN-1.0.0-Setup.exe) — حدود ۱۲۰ مگابایت
- [دانلود نصب‌کننده MSI](https://github.com/VitaNet-CRM/vitaVPN/releases/download/windows-v1.0.0/vitaVPN-1.0.0-x64.msi) — حدود ۶۸ مگابایت
- [فایل‌های نسخهٔ ویندوز و SHA-256](https://github.com/VitaNet-CRM/vitaVPN/releases/tag/windows-v1.0.0)

**فقط یکی از EXE یا MSI را نصب کنید.** هر دو همان برنامه را نصب می‌کنند و به نصب جداگانهٔ .NET نیاز ندارند. پیش از نصب، VPNها را خاموش کنید. اگر نسخهٔ آزمایشی ۱٫۱ روی کامپیوتر دارید، ابتدا آن را از تنظیمات ویندوز حذف کنید و سپس نسخهٔ ۱٫۰٫۰ را نصب کنید.

نسخهٔ ویندوز دارای حالت **پروکسی و تونل**، فهرست مسیرهای مستقیم برای IP و دامنه، انتخاب سرور، نمایش ترافیک و وضعیت اشتراک، منوی جمع‌شونده، پوستهٔ تیره و روشن و به‌روزرسانی امضاشده است. برای شروع، کد فعال‌سازی حساب خود را وارد کنید.

نصب‌کنندهٔ ویندوز فعلاً امضای ناشر Authenticode ندارد؛ اصالت فایل‌ها را با [SHA256SUMS.txt](https://github.com/VitaNet-CRM/vitaVPN/releases/download/windows-v1.0.0/SHA256SUMS.txt) بررسی کنید.

## اندروید — نسخهٔ ۱٫۰٫۰، ساخت ۴۲

- [arm64-v8a — مناسب بیشتر گوشی‌های جدید](https://github.com/VitaNet-CRM/vitaVPN/releases/download/v1.0.0/vitaVPN-v1.0.0-arm64-v8a.apk)
- [armeabi-v7a — مناسب گوشی‌های ARM قدیمی ۳۲ بیتی](https://github.com/VitaNet-CRM/vitaVPN/releases/download/v1.0.0/vitaVPN-v1.0.0-armeabi-v7a.apk)
- [فایل‌های نسخهٔ اندروید و SHA-256](https://github.com/VitaNet-CRM/vitaVPN/releases/tag/v1.0.0)

حداقل نسخهٔ لازم **Android 7.0 (API 24)** است. اگر معماری گوشی خود را نمی‌دانید، برای بیشتر گوشی‌های جدید `arm64-v8a` مناسب است. نسخهٔ اندروید با امضای رسمی برنامه روی نسخهٔ قبلی به‌روزرسانی می‌شود و نیازی به حذف آن ندارید.

## دربارهٔ سورس

این مخزن فقط برای دانلود فایل‌های نصب است. سورس اصلی هر دو برنامه **خصوصی و اختصاصی** است. فایل‌های خودکار `Source code (zip)` و `Source code (tar.gz)` در GitHub فقط محتوای همین مخزن عمومی را دارند و سورس برنامه‌ها نیستند.

Official vitaVPN downloads for **Windows and Android**.
