# دانلود رسمی vitaVPN برای Android

این مخزن محل انتشار عمومی فایل‌های نصب vitaVPN است. سورس اصلی برنامه خصوصی و اختصاصی است و در این مخزن منتشر نمی‌شود.

## دانلود نسخه v1.0.0

نسخهٔ **۱٫۰٫۰ — ساخت ۴۲** با امضای رسمی برنامه؛ قابل نصب به‌عنوان به‌روزرسانی نسخهٔ قبلی، بدون نیاز به حذف برنامه.

- [arm64-v8a — مناسب بیشتر گوشی‌های جدید](https://github.com/VitaNet-CRM/vitaVPN-Android/releases/download/v1.0.0/vitaVPN-v1.0.0-arm64-v8a.apk)
- [armeabi-v7a — مناسب گوشی‌های ARM قدیمی ۳۲ بیتی](https://github.com/VitaNet-CRM/vitaVPN-Android/releases/download/v1.0.0/vitaVPN-v1.0.0-armeabi-v7a.apk)

حداقل نسخهٔ لازم **Android 7.0 (API 24)** است. اگر از معماری گوشی خود مطمئن نیستید، برای بیشتر گوشی‌های جدید فایل `arm64-v8a` مناسب است.

برای بررسی سلامت فایل دانلودشده، SHA-256 آن را با [SHA256SUMS.txt](https://github.com/VitaNet-CRM/vitaVPN-Android/releases/download/v1.0.0/SHA256SUMS.txt) مقایسه کنید. [صفحهٔ Release v1.0.0](https://github.com/VitaNet-CRM/vitaVPN-Android/releases/tag/v1.0.0)

## دربارهٔ فایل‌های Source code

فایل‌های `Source code (zip)` و `Source code (tar.gz)` را GitHub به‌طور خودکار از محتوای همین مخزن عمومی در Tag نسخه می‌سازد. این بایگانی‌ها **سورس اصلی برنامه vitaVPN را ندارند**.

## English

This repository distributes official vitaVPN Android APKs. The application source is private and proprietary; it is not published here.

Download [arm64-v8a](https://github.com/VitaNet-CRM/vitaVPN-Android/releases/download/v1.0.0/vitaVPN-v1.0.0-arm64-v8a.apk) for most modern phones or [armeabi-v7a](https://github.com/VitaNet-CRM/vitaVPN-Android/releases/download/v1.0.0/vitaVPN-v1.0.0-armeabi-v7a.apk) for older 32-bit ARM phones. Requires Android 7.0 (API 24) or newer. Verify downloads against [SHA256SUMS.txt](https://github.com/VitaNet-CRM/vitaVPN-Android/releases/download/v1.0.0/SHA256SUMS.txt).
