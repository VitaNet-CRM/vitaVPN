# Android 1.0.23

**اندروید — ساخت ۱۴۱ اصلاح‌شده**

[دانلود نسخهٔ اصلی اندروید](https://github.com/VitaNet-CRM/vitaVPN/releases/tag/windows-v1.0.24)

نسخهٔ اصلی اندروید 1.0.23 — ساخت۱۴۱ اصلاح‌شده

• صفحهٔ آمار با وضعیت اشتراک، سهمیهٔ نامحدود یا حجمی، تمدید بعدی و سوابق خرید و تمدید از CRM؛ نمایش مبلغ همان اشتراک با کد فعال‌سازی. رسید همچنان خصوصی است.
• اشتراک فعال ابتدا و سبز، پایان‌یافته قرمز و تمدید در صف یشمی؛ حداکثر ده سابقه، پنج مورد در هر صفحه.
• بهبود سازگاری دریافت به‌روزرسانی و حفظ فعال‌سازی و تنظیمات هنگام ارتقا.
• مصرف و نام کاربر در خانه؛ اصلاح حرکت هاله، فاصلهٔ نور و ثابت‌ماندن علامت پاور هنگام اتصال.
• به‌روزرسانی هسته‌های Xray، WireGuard و AmneziaWG با حفظ فهرست کامل مسیرهای مجاز CRM.

APK همان معماری را روی نسخهٔ اصلی قبلی نصب کنید؛ برنامه را حذف نکنید تا فعال‌سازی و تنظیمات حفظ شوند. حداقل Android 7.0؛ چهار معماری موجود است.

اعتبارسنجی: ارتقای نسخهٔ اصلی از 1.0.22 به 1.0.23 با دانلود از CRM و نصب‌کنندهٔ اندروید روی شبیه‌ساز بررسی شد؛ فعال‌سازی، تنظیمات و انتخاب سرور حفظ شدند. نسخهٔ اصلی روی سامسونگ نیز ارتقا یافت. امضا، SHA-256 و هم‌ترازی 16KiB فایل‌ها بررسی شده‌اند. آزمون باتری بدون شارژ و پایش تازهٔ طولانی VPN در این مرحله انجام نشده است.

این مخزن برای فایل‌های انتشار است. سورس برنامه در مخزن خصوصی به‌روز شده؛ سورس تغییرات هستهٔ متن‌باز و مجوزهای آن در native-source-1.0.23-141.zip قرار دارد.
