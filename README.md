# Android 1.0.14 / Windows 1.0.11

دانلودهای اندروید و ویندوز در همین صفحه قرار دارند. برای بیشتر گوشی‌های جدید، APK با نام arm64-v8a مناسب است. برای ویندوز، فایل Setup معماری مناسب را انتخاب می‌کند؛ MSIهای x64 و x86 نیز موجودند.

اصلاح عمومی آزادشدن اپ پس از غیرفعال‌سازی از CRM، بازگشت صفحه‌های مختلف به فرم کد، و ورود دوباره با کد قبلی یا کد معتبر دیگر. پاسخ دیررس حساب قبلی نمی‌تواند حساب جدید را خارج کند. اختلال موقت CRM به‌تنهایی موجب خروج از حساب یا قطع اتصال سالم نمی‌شود. غیرفعال‌سازی اپ تغییری در دسترسی مستقل WireGuard و ثنایی ایجاد نمی‌کند.

کتابخانه‌های اندروید فشرده‌اند و امضای قبلی حفظ شده است. هش فایل‌ها در SHA256SUMS.txt قرار دارد. این نسخه به انتشار تازهٔ CRM نیاز ندارد.

آزمون‌های خودکار و نصب روی ویندوز x64 و شبیه‌ساز اندروید انجام شده‌اند؛ آزمون گوشی فیزیکی و ویندوز x86 روی سخت‌افزار جدا انجام نشده است.
