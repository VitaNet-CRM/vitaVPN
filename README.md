# VitaNet / vitaVPN

[صفحهٔ دانلود مشترک اندروید و ویندوز](https://github.com/VitaNet-CRM/vitaVPN/releases/tag/v1.0.20)

## Android 1.0.18 / Windows 1.0.18

دانلود اندروید و ویندوز در همین صفحه است. برای بیشتر گوشی‌های جدید arm64-v8a مناسب است. در ویندوز Setup معماری مناسب را انتخاب می‌کند؛ MSI آفلاین x64 و x86 هم موجود است.

- پشتیبانی از AmneziaWG در کنار Xray و WireGuard، برای مسیرهایی که سرویس شما اجازه می‌دهد.
- اصلاح راه‌اندازی تونل و اتصال AWG، همراه با ثبت مجوز محدود شبکه پیش از اتصال.
- بهبود قطع اتصال، لغو اتصال ناموفق و بازگرداندن تنظیمات شبکه هنگام خروج.
- آماده‌سازی و استفادهٔ مجدد از فهرست معتبر مسیرهای مستقیم ایران؛ بررسی اعتبار سرویس و عبور واقعی ترافیک حفظ شده است.
- نمایش نام سرویس، نام محصول تمدید بعدی و هشدارها؛ پیام بلند فضای کامل کارت پایین را می‌گیرد و پیام‌های کوتاه کنار هم می‌مانند.
- بهبود ظاهر تمدید و بستن فهرست سرورها با کلیک بیرون از فهرست در ویندوز.

روی نسخهٔ قبلی نصب کنید و برنامه را حذف نکنید تا فعال‌سازی و تنظیمات حفظ شوند. نصب ممکن است اتصال همان دستگاه را کوتاه قطع کند؛ انتشار فایل‌ها نیاز به توقف سایت یا VPN سرورها ندارد.

نسخهٔ Windows 1.0.18 روی سیستم ویندوز ۶۴بیتی مالک نصب شد؛ اتصال TUN و AWG، اینترنت، اتصال مجدد و حفظ فعال‌سازی تأیید شدند. فایل‌های Android همان خروجی قبلاً منتشرشدهٔ 1.0.18 / 84 هستند و تغییر نکرده‌اند.

حداقل Android 7.0؛ Windows 10/11 x64 و Windows 10 x86. سخت‌افزار Windows x86 و گذار طبیعی تمدید مالی آزمون نشده‌اند. در اندروید ۳۲بیتی و سیستم‌عامل ویندوز ۳۲بیتی AWG ارائه نمی‌شود؛ WireGuard و Xray حفظ شده‌اند. امضای APK و اعتبارسنجی امضا/هش آپدیت ویندوز حفظ شده؛ نصب‌کنندهٔ ویندوز هنوز Authenticode ندارد.

هش فایل‌ها در SHA256SUMS.txt است. نسخهٔ عمومی قبلی برای بازگشت عرضه محفوظ است؛ اپ نصب‌شده خودکار به نسخهٔ قبلی برنمی‌گردد. سورس اپ‌ها خصوصی است؛ آرشیو خودکار گیت‌هاب متعلق به مخزن دانلود است.
