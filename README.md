# Android 1.0.15 / Windows 1.0.12

دانلودهای اندروید و ویندوز در همین صفحه قرار دارند. برای بیشتر گوشی‌های جدید APK با نام arm64-v8a مناسب است. در ویندوز فایل Setup معماری مناسب را انتخاب می‌کند؛ نصب‌کننده‌های آفلاین x64 و x86 نیز موجودند. فقط یکی را نصب کنید.

- تنظیمات ساده‌تر، دکمهٔ کپی کد فعال‌سازی و غیرفعال‌سازی با تأیید دوم؛ در اندروید دکمه‌های آبی و قرمز واضح و در دسترس‌اند.
- نمایش واضح آماده‌بودن به‌روزرسانی، دکمهٔ دریافت و درصد پیشرفت؛ پیام‌ها باعث جابه‌جایی صفحه نمی‌شوند.
- دریافت فهرست مدیریت‌شدهٔ مسیرهای ایران از سرور، با VPN روشن یا خاموش و از ارتباط خارج از تونل؛ فهرست جدید در اتصال بعدی اعمال می‌شود. مسیرهای سپه و رسالت در فهرست مرکزی بررسی شده‌اند؛ موفقیت ورود بانکی به وضعیت سایت بانک هم وابسته است.
- بهبود دریافت تغییرات سرور و اینباند و مسیر IPv4. در ویندوز شبکه‌های خصوصی مستقیم می‌مانند و اجرای دوبارهٔ میان‌بر، همان پنجرهٔ باز را نمایش می‌دهد.
- جدول اسکرول‌دار مسیرهای مستقیم ویندوز با ویرایش، ذخیره/انصراف و حذف هر ردیف.

فایل مناسب را روی نسخهٔ قبلی نصب کنید تا فعال‌سازی حفظ شود؛ VPN همان دستگاه هنگام نصب ممکن است کوتاه قطع شود. انتشار فایل‌ها توقف سایت یا سرویس VPN سرورها ندارد. کپی کد برای نصب‌های قدیمی که اصل کد را نگه نداشته‌اند، تا فعال‌سازی دوباره در نسخهٔ جدید در دسترس نیست.

امضای قبلی اندروید و اعتبارسنجی امضا/هش به‌روزرسانی ویندوز حفظ شده است. نصب‌کننده‌های ویندوز امضای Authenticode ندارند. حداقل Android 7.0؛ Windows 10/11 x64 و Windows 10 x86. ویندوز ARM64 پشتیبانی نمی‌شود.

آزمون‌های خودکار، نصب آزمایشی روی ویندوز x64 و شبیه‌ساز Pixel و دریافت فهرست با VPN روشن/خاموش انجام شده‌اند. تست گوشی فیزیکی، Windows x86 روی سخت‌افزار جدا، پذیرش نهایی TUN/WFP با دسترسی مدیر و ورود واقعی بانکی کامل نشده‌اند. هش همهٔ فایل‌ها در SHA256SUMS.txt است؛ نسخه‌های قبلی محفوظ‌اند. سورس برنامه‌ها خصوصی است و آرشیوهای خودکار گیت‌هاب مربوط به مخزن دانلود هستند.
