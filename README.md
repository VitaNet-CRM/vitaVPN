# VitaNet / vitaVPN

[صفحهٔ دانلود مشترک اندروید و ویندوز](https://github.com/VitaNet-CRM/vitaVPN/releases/tag/v1.0.16)

## Android 1.0.15 / Windows 1.0.13

فایل‌های اندروید و ویندوز در همین صفحه قرار دارند. برای ویندوز، Setup معماری مناسب را انتخاب می‌کند؛ فایل‌های MSI برای نصب مستقیم نیز موجودند. اندروید arm64-v8a برای بیشتر گوشی‌های جدید مناسب است.

### Windows 1.0.13

- رفع خطای راه‌اندازی حالت تونل در ویندوز.
- اصلاح قطع اتصال و تلاش مجدد هنگام خطای بازیابی پراکسی.
- حفظ فعال‌سازی و تنظیمات هنگام ارتقا؛ برای آپدیت نیازی به حذف برنامه نیست.

از نسخهٔ 1.0.12 به‌روزرسانی کنید. این اصلاح روی ویندوز واقعی و توسط کاربر گزارش‌دهنده تأیید شده است. نسخهٔ ۳۲بیتی ساخته و بررسی شده، اما آزمون روی سخت‌افزار ۳۲بیتی انجام نشده است.

### Android 1.0.15

همان فایل‌های انتشار قبلی، بدون تغییر. دریافت کد فعال‌سازی از تصویر QR، کپی کد اصلی، نمایش اعتبار و روزهای مانده و بهبود پیام‌ها و مسیرهای مستقیم.
